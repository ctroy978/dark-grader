# Relic art contract

Place one transparent PNG for each complete reward image in this directory:

- `bulwark_sigil.png`
- `ember_whetstone.png`
- `purity_charm.png`
- `healing_potion.png`

Use a consistent square canvas (512×512 preferred), centered artwork, and a
transparent background. The client uses readable symbol fallbacks when an asset
is absent, so art can be supplied without code changes.
