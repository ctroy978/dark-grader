# Grovekeeper art

Grovekeeper is the healing-over-time Lifebinder class. The engine currently
stores this class under the internal archetype id `Lifebinder`.

Add these PNG files here:

- `standing.png` — idle portrait; minimum asset needed for an art check
- `attack.png` — renewal cast
- `hit.png` — taking damage
- `ice.png` — Frozen pose
- `death.png` — fallen pose

Recommended party-art size: approximately 5:6, such as 768×922. Missing poses
fall back to the generated Grovekeeper placeholder.
