# Thornmender art

Thornmender is the rescue-healing Lifebinder class. The engine currently stores
this class under the legacy internal archetype id `Healer`.

Add these PNG files here:

- `standing.png` — idle portrait; minimum asset needed for an art check
- `attack.png` — rescue-heal cast
- `hit.png` — taking damage
- `ice.png` — Frozen pose
- `death.png` — fallen pose

Recommended party-art size: approximately 5:6, such as 768×922. Missing poses
fall back to the generated Thornmender placeholder.
